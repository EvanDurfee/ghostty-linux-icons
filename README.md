# Ghostty Linux Icons

Takes the ghostty linux icon from the ghostty source code and modifies
it to match my terminal theme, as opposed to the default blue.

Inspired by [Json Long's work](https://github.com/jasonlong/ghostty-theme-icons), but for linux instead of macintosh.

## Customizing

Updated the icon source, then export and overwrite ghostty.png

Then, run `export-icons.sh` with imagemagick installed to generate the
different sizes.

## Installation

Run `install-icons.sh` for a user install.
